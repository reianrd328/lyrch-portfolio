# LYRCH Digital Command Center & Portfolio CMS - Project Plan

## 1. Vision & Identity
- **Concept**: Digital Command Center
- **Core Identity**: IT Support Specialist + Full-Stack Developer + AI Creator
- **Motto**: "THINK → SOLVE → BUILD → CREATE" — Ideas into Real Solutions.
- **Visual Style**: Cybernetic dark interface, electric cyan (#00f0ff) & neon purple (#8a2be2, #a855f7) glowing elements, glassmorphism, telemetry indicators, responsive layout.

## 2. Architecture & Modules
The system separates public presentation from private administration:
- **Public Portal**: High-impact, futuristic command center featuring live metrics, interactive projects, AI video showcase, tech stack matrix, and contact dispatch.
- **Admin CMS (`/admin`)**: Private management dashboard allowing full CRUD for projects, videos, gallery items, documents, skills, and activities.
- **Persistence Layer**: MySQL database via SQLAlchemy models with media assets managed in `uploads/`.

## 3. Development Phases
- **PHASE 1**: Personal Portfolio CMS & Work Manager Foundation (Tree, Config, Models, Auth, Dashboard)
- **PHASE 2**: Cybernetic UI & Command Center Theme Implementation
- **PHASE 3**: Public Command Center Core & Telemetry Widgets
- **PHASE 4**: Project Case Studies & Interactive Details
- **PHASE 5**: AI Lab & AI Video Studio Player
- **PHASE 6**: Document Repository & Resume Management
- **PHASE 7**: Admin CMS Refinements & Media Upload Pipelines
- **PHASE 8**: Mobile Optimization & Responsive Command Bar
- **PHASE 9**: Security Hardening & Rate Limiting
- **PHASE 10**: Testing, Build Verification & Production Deployment
