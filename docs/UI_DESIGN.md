# UI Design System: Futuristic Cybernetic Command Center

## Design Philosophy
The interface emulates a futuristic aerospace / cyber-security Operations Dashboard. It blends functional data density with cinematic neon aesthetics.

## Color Palette
- **Background Primary**: `#050814` (Deep Space Navy)
- **Background Secondary / Panels**: `#0b112c` / `#0f1738` with 70% opacity and backdrop blur
- **Primary Accent (Cyan)**: `#00f0ff` (Telemetry glow, active states, metrics)
- **Secondary Accent (Purple)**: `#a855f7` / `#8b5cf6` (Buttons, avatars, neon highlights)
- **Highlight (Pink/Magenta)**: `#ec4899` (Secondary badges, gradient accents)
- **Status Colors**:
  - Live / Online: `#10b981` (Emerald pulsing dot)
  - Beta: `#3b82f6` (Cobalt blue)
  - Demo: `#f59e0b` (Amber)
  - Critical / Urgent: `#ef4444` (Crimson)
- **Text**:
  - Primary: `#f8fafc` (Slate 50)
  - Secondary: `#94a3b8` (Slate 400)
  - Muted: `#64748b` (Slate 500)

## Layout Components
1. **Command Header**: System status badge, live UTC/Local clock, search bar, mode switch.
2. **Left Navigation Rail**: Core modules, command center shortcuts, inspiration capsule.
3. **Hero Command Hub**: Avatar frame with pulsing gradient ring, telemetry stats, regional deployment map.
4. **Metrics Bar**: 5 telemetry glass cards displaying mission-critical metrics.
5. **Project Grid**: Holographic cards featuring interactive previews, technology tags, and action buttons.
6. **Right Telemetry Column**: AI video studio player preview, live event stream, quick contact widget.
